Problem

Routine storage expansion was a manual, platform-specific task across VMware, Azure, and AWS. A single server change regularly consumed more than 30 minutes, and repeating the process across multiple systems increased operational toil and the opportunity for inconsistent execution.

Approach

I built reusable, pipeline-driven workflows using Ansible/AWX, PowerShell, and Terraform. Infrastructure changes moved through Git and pull-request review before parameterized automation executed the appropriate platform workflow. The same operating pattern could handle individual servers or coordinated multi-server changes without relying on separate manual procedures for every platform.

Result

Execution dropped from 30+ minutes to approximately 2–5 minutes per server—a 6–15× improvement. The workflow made a common lifecycle task faster, repeatable, reviewable, and safer to run at enterprise scale.
