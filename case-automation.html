02 / HYBRID AUTOMATION

Hybrid Infrastructure Automation

Storage expansion across VMware, Azure, and AWS through a consistent, parameterized workflow.

  1. Reviewed request
  2. Bitbucket pipeline

The problem

Routine disk expansion required manual, platform-specific steps. A single server change regularly took more than 30 minutes, and repeating it across several systems multiplied the operational effort.

What I built

Reusable Ansible/AWX and PowerShell workflows connected to pipeline-driven execution. Engineers supplied target systems and change parameters, and the automation selected the platform-specific workflow for individual or multi-server changes.

The architecture decision

Keep a consistent request and execution pattern while preserving the differences between VMware, Azure, and AWS. The operator should not have to repeat each platform’s manual sequence for every server.

The result

Reported routine execution fell from more than 30 minutes to approximately 2–5 minutes per server. This measures the execution step; it does not describe the full change-approval lifecycle.
